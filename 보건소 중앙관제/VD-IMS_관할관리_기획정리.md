## 1. 배경과 목표

남동구보건소는 위탁의료기관 25곳을 관할한다. 지금 빔스 메뉴(재고 현황, 이상반응 현황, 유효기간 임박 등)는 보건소 자체 데이터만 보여준다. 보건소 담당자가 관할 위탁기관 25곳의 접종·재고·유효기한·이상반응을 한 곳에서 확인하고 조치할 수 있는 메뉴를 추가한다.

## 3. 프로토타입 현재 상태 (v4)

### 메뉴 (REGION MANAGEMENT · 보건소)
1. 관할기관 현황 — KPI 4개, 인구통계·이상반응 차트, 남동구 행정동 지도(마커·필터·호버 팝업), 주요 알림
2. 관할기관 목록 — 기관별 지표 표, 상태 필터, 검색, 정렬, "이상 지표 기관만" 스위치
3. 기관별 접종현황 — 시간대별 차트, 기관별 표, 접종상세
4. 기관별 재고현황 — 로트별로 펼쳐지는 재고표, 발주 권장 수량
5. 유효기한 임박 — 만료 미폐기, 7일·30일 이내 만료, D-day
6. 기관별 이상반응 — 상위 10개 기관 차트, 전체·일반·기저질환 탭

공통: 지역·기관·감염병·백신 필터와 선택항목 칩, 기관 상세 모달(기관 정보/접종 현황/이상 반응/재고 현황 탭), 담당자 알림톡 발송 버튼(동작 없음), 표 페이지네이션.

위탁기관 25곳(메디체크병원, 연세플러스의원 등), 백신 5종(보령플루V테트라백신주, 유박스비프리필드주, 프리베나13주, 스카이조스터주, 가다실9). 모두 가상 데이터이며 지도 경계도 목업.

## 4. 결정 사항 (2026-10-21)

1. **기존 메뉴에 조회 범위 필터 추가** — 재고 현황·이상반응 현황·유효기간 임박 등 기존 메뉴는 그대로 두고, 보건소 계정에만 `우리 보건소(기본) / 관할 전체 / 위탁기관 선택` 필터를 붙인다. 다른 기관 데이터는 조회만 가능.
   - 필터 추가: 재고 현황, 사용 내역, 전체 접종 현황, 이상반응 현황, 자가체크 내역, 유효기간 임박, 백신 접종 내역(개인정보 범위 확인 후)
   - 추가하지 않음: 재고 관리, 일지 관리, 자동 등록, 상품 관리, 발주 관리
   - 신규 메뉴는 관할기관 현황, 관할기관 목록 2개로 축소
2. **데이터 수신 상태 삭제** — 보건소와 위탁기관이 같은 서버(자사 서버 또는 보건소용 G클라우드)를 쓰므로 수신 지연·미수신 개념이 없음. 수신 열·KPI·미수신 알림·회색 마커 삭제. 대안으로 "최근 접종 등록일" 표시는 검토 중.
3. **알림 처리 흐름** — 대상은 관할기관 현황 오른쪽 "주요 알림" 패널과 헤더 종 아이콘. 알림별 처리 상태(신규 → 확인 → 조치 중 → 종결)와 메모, 기관별 묶음. 알림톡은 처리 수단으로 연결.

## 5. 검토 의견 (서비스 기획·CTO 관점)

### 삭제·축소
- 관할 하위 메뉴 6개 → 2개 (결정 1 반영 예정)
- 관제 첫 화면의 연령·성별·통증 분포 차트는 통계·보고서 영역으로 이동
- 접종상세의 피접종자 이름(마스킹 포함) 제거, 개인 단위 조회는 사유 기록 후 허용

### 수정
- 상태 판정을 건수 → 비율로: 접종 1,000건당 이상반응 접수율, 중증은 1건이라도 위험, 재고는 소진 예상일(잔여 ÷ 최근 7일 일평균) 기준, 기준값은 보건소별 설정
- 이상반응 용어 구분: 자가체크 이상 응답 / 의료기관 확인 건 / 신고 완료 건
- 기관 상세: 모달 → 페이지(링크 공유, 뒤로 가기)
- KPI 카드마다 기간 기준(금일·조회기간·누적) 명시
- 용어 통일: "유효기간 임박"(기존 메뉴명)으로 맞춤

### 보완
- 대상 인구 대비 **접종률**(행정동·연령군별) — 보건소 핵심 지표
- 권한·법적 근거(위탁계약, 감염병예방법, 데이터 공유 동의), 역할 체계, 열람 감사 로그
- 조치 기능: 기관 간 재고 재배분 요청, 폐기 확인 요청, 역학조사 요청, 알림톡 템플릿 승인·발송 이력
- 예방접종통합관리시스템 등록 누락 점검(빔스 자동 등록과 연계)
- 월간 관할 현황 보고서(PDF·Excel)
- 기술: 서버 측 사전 집계, 공공 행정동 경계(GeoJSON) + 카카오/네이버 지도, 화면별 기준 시각 표시
- G클라우드 사용 시 민간 위탁기관 접속 방식(CSAP 등급, 접속망) 확인
