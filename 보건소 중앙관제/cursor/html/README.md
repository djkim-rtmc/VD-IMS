# 보건소 중앙관제 — HTML 프로토타입

## 공식 기준 화면 (Claude 첨부 동일)

**브랜치:** `git checkout cursor/rtmc-design-unify` 후 미리보기 (main만 보면 이전/다른 화면일 수 있음).

| [`VD-IMS 관할기관 현황.html`](./VD-IMS%20관할기관%20현황.html) | 위 파일과 **동일 내용**(기존 북마크·링크용 별칭) |

**로컬 미리보기:** `cd` 이 폴더 → `python3 -m http.server 8765`

- 기준 화면: `http://127.0.0.1:8765/VD-IMS_관할기관현황_프로토타입.html`

`file://` 더블클릭도 동일 렌더링(외부 CSS 없음).
