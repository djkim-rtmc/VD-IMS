# Cursor Browser에서 HTML 실시간 수정하기

Cloud Try Live 없이 **본인 PC의 Cursor**에서 에디터 + Browser를 나란히 쓰는 방법입니다.

## 1. 준비 (한 번)

```bash
git clone https://github.com/djkim-rtmc/VD-IMS.git
cd VD-IMS
git checkout cursor/bhc-html-prototypes
```

Cursor에서 **File → Open Folder** → `VD-IMS` (Project 채팅만 열린 상태가 아니라 **폴더 워크스페이스**).

## 2. 로컬 서버 (매 작업 세션)

Cursor **통합 터미널** (PC에서 실행):

```bash
cd "보건소 중앙관제/프로토타입"
python3 -m http.server 8765 --bind 127.0.0.1
```

`Serving HTTP on 127.0.0.1 port 8765` 가 보이면 OK.

## 3. Cursor Browser 열기

1. **View → Editor Layout → Split** (또는 HTML 파일 옆 **Open in Browser** / Simple Browser)
2. Browser 주소: `http://127.0.0.1:8765/통합-대시보드.html`
3. HTML·CSS 파일을 편집 → **저장 (Ctrl/Cmd+S)** → Browser **새로고침**

> Chat 패널 Browser만 쓰면 VM URL(`127.0.0.1`)과 PC 서버가 어긋날 수 있습니다. **로컬 워크스페이스 + 로컬 터미널 서버**가 맞는 조합입니다.

## 4. Agent와 함께 수정

- **같은 PC 워크스페이스**에서 Cursor Agent에게 `보건소 중앙관제/프로토타입/*.html` 수정을 요청
- 저장 후 Browser 새로고침으로 확인
- Project(Cloud) 채팅만 쓰면 파일은 GitHub/VM에 있고 PC Browser와 **실시간 동기화되지 않음** → 로컬 clone 또는 PR pull 필요

## 5. (선택) 저장할 때마다 자동 새로고침

Node가 있으면:

```bash
npx --yes live-server --port=8765 --host=127.0.0.1 --no-browser
```

Browser는 한 번 `http://127.0.0.1:8765/통합-대시보드.html` 로 연 뒤, 저장 시 자동 갱신됩니다.

## 자주 나는 오류

| 증상 | 원인 | 해결 |
|------|------|------|
| ERR_CONNECTION_REFUSED | PC에 서버 없음, 또는 VM URL을 PC Browser에서 연 경우 | PC 터미널에서 `http.server` 실행 |
| Cloud agent view unavailable | Try Live 불가 | 이 문서대로 **로컬** 워크스페이스 사용 |
| 수정이 Browser에 안 보임 | 다른 브랜치/경로 편집 | `cursor/bhc-html-prototypes` + `프로토타입/` 경로 확인 |
