## 실행

브라우저에서 html 파일을 열면 됩니다. 네트워크 필요: Google Fonts, Chart.js CDN.

## 화면 구조 (관할 관리 · subnav)

1. **관할기관 현황** (`#overview`) — KPI, 차트, 남동구 행정동 지도, 알림
2. **관할기관 목록** (`#orgs`) — 정렬·필터·종합 상태
3. **기관별 접종현황** (`#vacc`) — 시간대별 차트, 접종 상세
4. **기관별 재고현황** (`#stock`) — 로트 펼치기, 안전/적정
5. **유효기한 임박** (`#expiry`) — 30일·만료 미폐기
6. **기관별 이상반응** (`#adverse`) — 통증 1~5, 자가체크 연계 필드(목록에 응답률)

사이드 레일에는 VD-IMS 기존 메뉴(재고·접종·자가체크·비대면 상담 등) + **REGION MANAGEMENT · 보건소** 구역이 함께 표시됩니다.
