# 중앙관리시스템 개발지시서 (2026-02-09)

## 목적

관할 의료기관의 **접종·재고·이상반응** 데이터를 지역 보건소 관점에서 통합 모니터링하고, 재분배·조치 워크플로를 지원한다.

## 범위 (프로토타입)

- RTMC VD-IMS UI 셸(좌측 레일 + 상단 헤더) 준수
- 목(mock) 데이터 · 한국어 UI · 화면 간 상대 링크
- 프로덕션 API·React 앱 구현은 본 지시서 범위 외

## 우선 화면

1. 통합 대시보드 (P-MVYKEQ)
2. 재고 관리 — 재분배 추천·8단계 승인 상세
3. 이상반응 관리 — 모니터링·차트
4. 알림/조치 관리
5. 관할기관 현황 · 기관 상세

## VD-IMS 연동 원칙

- 자가체크 4회(3·48·72·168h) 필드 표준
- AI 심각도: 이용자 비노출, 의료진 **참고 분류**
- KOI 비대면 상담: VD-IMS는 **상태값**만, 상세는 제3자 화면
